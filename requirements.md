# Requirements – AutomationExercise

## 1. User Registration

- The system should allow new users to create an account with valid data
- The system should validate required fields during registration
- The system should prevent registration with invalid or incomplete data

## 2. User Login

- The system should allow users to log in with valid credentials
- The system should display an error message for invalid login attempts

## 3. Product Browsing

- The system should display available products
- The user should be able to view product details
- The user should be able to navigate between product listings

## 4. Navigation

- The user should be able to navigate between main sections (Home, Products, Login, Cart)
- The navigation should be consistent across pages

## 5. Form Validation

- The system should validate required fields in forms
- The system should prevent submission of invalid data
